# J-Quants API

> REST API providing historical Japanese stock market data (equities, derivatives, indices, financials) operated by Japan Exchange Group (JPX). Subscription-based service for individual investors only. Current version: V2. V1 is deprecated.

日本取引所グループが運営する日本株式市場データ配信APIです。株価・先物・オプション・指数・財務情報などのヒストリカルデータをREST APIおよびCSV形式で提供します。個人投資家向けのサブスクリプションサービスです。

CAUTION:
This service is intended for individual investors only. Commercial use, academic/institutional research, and use by institutional investor quantitative teams are strictly prohibited under JPX Terms of Service.

本サービスは個人投資家専用です。商用利用・学術・機関投資家のクオンツ運用目的での利用はJPX利用規約により固く禁止されています。

**Base URL**: `https://api.jquants.com/v2/`
**Portal**: https://jpx-jquants.com
**Auth**: API key via `x-api-key` header (obtain from dashboard after subscription)

IMPORTANT:
V1 API (/v1/... endpoints) is deprecated. Users registered on/after 2025-12-22 must use V2 only. All V1 users should migrate to V2 immediately. Token-based auth from V1 is abolished in V2.

Automated access must stay within plan rate limits. Unauthorized scraping, credential abuse, and circumvention of subscription restrictions are prohibited under JPX Terms of Service. Commercial use, academic/institutional research, and institutional investor quant operations are also strictly prohibited.
